## Recommended Database Fields

Each RSS source should be stored with:

- `name`
- `url`
- `category`
- `country`
- `language`
- `enabled`
- `priority`
- `fetch_interval`
- `last_fetched_at`
- `last_success_at`
- `last_error`
- `error_count`
- `created_at`
- `updated_at`

---

## Default Configuration

New feeds should use:

- enabled: true
- language: en
- fetch_interval: 15 minutes
- priority: normal
- error_count: 0

Administrators should be able to enable/disable feeds from the VNTV admin dashboard without changing application code.
